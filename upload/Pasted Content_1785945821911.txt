## Part 1 · `/api/v1/invite-requests/route.ts`

The homepage "Request an invite" form posts here. It creates a **prospect** (a business wanting to join), which your Super Admin reviews and invites. Public route, Zod-validated, duplicate-checked.

```ts
// src/app/api/v1/invite-requests/route.ts
import { NextResponse } from 'next/server';
import { db } from '@/lib/db';
import { prospects } from '@/lib/db/schema';
import { eq } from 'drizzle-orm';
import { z } from 'zod';

const inviteRequestSchema = z.object({
  restaurantName: z.string().min(2).max(120),
  ownerName: z.string().min(2).max(120),
  phone: z.string().min(9).max(20),
});

export async function POST(request: Request) {
  // Build resilience: the build passed with zero env vars, so db may be null.
  if (!db) {
    return NextResponse.json(
      { error: { code: 'DATABASE_NOT_CONFIGURED', message: 'We could not process your request right now.' } },
      { status: 503 },
    );
  }

  let body: unknown;
  try {
    body = await request.json();
  } catch {
    return NextResponse.json({ error: { code: 'INVALID_JSON' } }, { status: 400 });
  }

  const parsed = inviteRequestSchema.safeParse(body);
  if (!parsed.success) {
    return NextResponse.json(
      { error: { code: 'VALIDATION', details: parsed.error.flatten().fieldErrors } },
      { status: 400 },
    );
  }

  const { restaurantName, ownerName, phone } = parsed.data;

  // Duplicate check: don't create two prospects for the same phone.
  const [existing] = await db
    .select({ id: prospects.id })
    .from(prospects)
    .where(eq(prospects.phone, phone))
    .limit(1);

  if (existing) {
    // Return success anyway — don't leak that they already requested.
    return NextResponse.json({ success: true, alreadyRequested: true });
  }

  try {
    await db.insert(prospects).values({
      businessName: restaurantName,
      ownerName,
      phone,
      industry: 'restaurant',
      status: 'new',
      source: 'homepage',
    });
  } catch (e) {
    console.error('[invite-requests] insert failed', e);
    return NextResponse.json({ error: { code: 'INTERNAL' } }, { status: 500 });
  }

  return NextResponse.json({ success: true });
}
```

### `src/app/api/v1/hub/join/route.ts` (the join endpoint)

```ts
// src/app/api/v1/hub/join/route.ts
import { NextResponse } from 'next/server';
import { db } from '@/lib/db';
import { guests, loyaltyTransactions, tenants } from '@/lib/db/schema';
import { and, eq } from 'drizzle-orm';
import { z } from 'zod';
import { sendMessageToGuest } from '@/modules/whatsapp/send';

const joinSchema = z.object({
  tenantId: z.string().uuid(),
  name: z.string().min(1).max(120),
  phone: z.string().min(9).max(20),
  birthday: z.string().optional(),
  source: z.string().max(50).default('hub'),
});

export async function POST(request: Request) {
  if (!db) {
    return NextResponse.json({ error: { code: 'DATABASE_NOT_CONFIGURED' } }, { status: 503 });
  }

  const parsed = joinSchema.safeParse(await request.json().catch(() => null));
  if (!parsed.success) {
    return NextResponse.json({ error: { code: 'VALIDATION', details: parsed.error.flatten().fieldErrors } }, { status: 400 });
  }
  const { tenantId, name, phone, birthday, source } = parsed.data;

  // Tenant must exist
  const [tenant] = await db.select().from(tenants).where(eq(tenants.id, tenantId)).limit(1);
  if (!tenant) return NextResponse.json({ error: { code: 'TENANT_NOT_FOUND' } }, { status: 404 });

  // Already a member? Don't double-create.
  const [existing] = await db
    .select({ id: guests.id })
    .from(guests)
    .where(and(eq(guests.tenantId, tenantId), eq(guests.phone, phone)))
    .limit(1);

  if (existing) {
    return NextResponse.json({ success: true, alreadyMember: true });
  }

  const WELCOME_BONUS = 10;

  const [guest] = await db.insert(guests).values({
    tenantId,
    phone,
    name,
    birthday: birthday ? new Date(birthday) : null,
    status: 'active',
    pointsBalance: WELCOME_BONUS,
    joinedAt: new Date(),
    source,
  }).returning();

  await db.insert(loyaltyTransactions).values({
    tenantId,
    guestId: guest.id,
    type: 'welcome',
    points: WELCOME_BONUS,
    description: 'Welcome bonus (Restaurant Hub join)',
  });

  // Welcome message — sendMessageToGuest degrades gracefully if WhatsApp isn't connected.
  await sendMessageToGuest(tenantId, phone,
    `Welcome to ${tenant.name}! 🎉 You've got ${WELCOME_BONUS} ${tenant.currencyName} to start. Text BALANCE anytime to check, or REDEEM when you're here.`,
    { guestId: guest.id, handledBy: 'automation' },
  );

  return NextResponse.json({ success: true, whatsappConnected: tenant.whatsappConnected });
}
```

## 1 · How the AI features work

Orderly has four AI surfaces, all on the **Vercel AI SDK**, and all built on one rule: **the model composes language; it never invents facts.** Every fact (price, hours, balance, availability) comes from a **tool call** into your own data.

| Surface | What it does | How it stays truthful |
|---|---|---|
| **Concierge** | Answers guest questions, takes bookings on WhatsApp | Tool calls to menu/hours/bookings + RAG for policies |
| **Sentiment** | Routes reviews positive→Google / negative→manager | Keyword + LLM classification on the review text |
| **Insights** | Plain-English weekly coaching | Generated *from* your live numbers, never generic |
| **Smart targeting** | Picks *which* guests get a campaign | Rules + data (visits, spend, location), not guesswork |

The concierge is given **tools** (typed, tenant-scoped, permission-checked):

```
get_menu(category?)        → queries menu_items          (always current)
get_business_info()        → hours, address, phone, GPS
get_specials()             → today's specials
check_availability(...)    → bookings engine
create_booking(...)        → writes a reservation
get_loyalty_balance(phone) → guest points
search_knowledge(query)    → RAG over the owner's uploaded docs
```

**The key architectural split** (this answers half of your question 2):

- **Structured, changing data** (menu, prices, hours, availability, balance) → **tool calls**. Never RAG. If you RAG the menu, prices go stale the moment you change a dish. A tool call is always live.
- **Unstructured knowledge** (your story, policies, FAQ, "do you allow dogs?", allergen philosophy) → **RAG** (the knowledge base below).

System prompt shape: *"You are the friendly concierge for {restaurant}. Answer only from your tools and knowledge base. Never invent prices, hours, or facts. If you don't know, say so and offer to connect them with the restaurant."*

```ts
import { openai } from '@ai-sdk/openai';

function chunkText(text: string, size = 800, overlap = 100): string[] {
  const out: string[] = [];
  for (let i = 0; i < text.length; i += size - overlap) out.push(text.slice(i, i + size));
  return out.filter((c) => c.trim().length > 40);
}

// Jina Reader turns ANY url (even JS-rendered sites) into clean markdown. Free tier.
async function fetchUrlAsText(url: string): Promise<string> {
  const res = await fetch(`https://r.jina.ai/${url}`, { headers: { Accept: 'text/plain' } });
  if (!res.ok) throw new Error('Could not read that URL');
  return res.text();
}

async function parsePdf(buffer: ArrayBuffer): Promise<string> {
  const pdf = await getDocumentProxy(new Uint8Array(buffer));
  const { text } = await extractText(pdf, { mergePages: true });
  return Array.isArray(text) ? text.join('\n') : text;
}

export async function POST(request: Request) {
  if (!db) return NextResponse.json({ error: { code: 'DATABASE_NOT_CONFIGURED' } }, { status: 503 });
  try {
    const { tenant } = await requireTenantContext();
    const ct = request.headers.get('content-type') || '';

    let rawText = '', ref = '', type: 'url' | 'pdf' = 'url';

    if (ct.includes('application/json')) {
      const parsed = z.object({ url: z.string().url() }).safeParse(await request.json());
      if (!parsed.success) return NextResponse.json({ error: { code: 'VALIDATION' } }, { status: 400 });
      ref = parsed.data.url;
      rawText = await fetchUrlAsText(ref);
    } else {
      const file = (await request.formData()).get('file') as File | null;
      if (!file) return NextResponse.json({ error: { code: 'NO_FILE' } }, { status: 400 });
      ref = file.name; type = 'pdf';
      rawText = await parsePdf(await file.arrayBuffer());
    }

    if (rawText.trim().length < 50) {
      return NextResponse.json({ error: { code: 'EMPTY_CONTENT', message: 'Could not extract enough text from that source.' } }, { status: 422 });
    }

    const [source] = await db.insert(knowledgeSources).values({
      tenantId: tenant.id, type, url: type === 'url' ? ref : null,
      filename: type === 'pdf' ? ref : null, status: 'processing',
    }).returning();

    try {
      const chunks = chunkText(rawText);
      const { embeddings } = await embedMany({ model: openai.embedding('text-embedding-3-small'), values: chunks });
      await db.insert(knowledgeChunks).values(
        chunks.map((content, i) => ({ tenantId: tenant.id, sourceId: source.id, content, embedding: embeddings[i] })),
      );
      await db.update(knowledgeSources).set({ status: 'ready' }).where(eq(knowledgeSources.id, source.id));
      return NextResponse.json({ success: true, chunks: chunks.length });
    } catch (e) {
      await db.update(knowledgeSources).set({ status: 'failed', error: String(e) }).where(eq(knowledgeSources.id, source.id));
      throw e;
    }
  } catch (e) {
    return NextResponse.json({ error: { code: 'INGEST_FAILED', message: e instanceof Error ? e.message : 'Unknown' } }, { status: 500 });
  }
}
```

## 4 · What "success — ready for 1,000 tenants" actually means

I'll be straight: "ready for 1,000" is a **set of gates you pass**, not a switch you flip. And you validate at 1 tenant long before you need 1,000. Here's the honest definition.

**Success = all of these are true:**

1. **The one-tenant dress rehearsal passes end-to-end.** Claim → connect WhatsApp → a real phone texts `JOIN` and gets a reply → redeems a GPS-gated reward → a PayFast **sandbox** transaction completes via webhook → insights render. This is the single most important proof. If this works for one restaurant, the machine works.

2. **Multi-tenant isolation is verified.** Tenant A can never see Tenant B's guests, menu, knowledge, or WhatsApp. You run cross-tenant leak tests (NAHALABS §5) and they pass. This is the difference between a product and a liability.

3. **The three external dependencies are proven at small scale:** Evolution (a real WhatsApp round-trip), PayFast (a real sandbox IPN with all four checks), and the AI (a grounded concierge answer pulled from a tool/knowledge, not invented).

4. **Deploy is resilient and verified against production:** builds green with zero env vars, `/api/v1/selftest` green on the live URL, Playwright E2E green **against the production URL** (not localhost).

5. **The scaling bottlenecks are identified and planned** (known, not necessarily solved on day one):
   - 🔴 **Evolution API is the #1 bottleneck.** One WhatsApp instance per tenant means 1,000 instances. A single free Render instance will not hold that. You'll need dedicated/larger Evolution servers or a managed WhatsApp provider well before 1,000. Plan for this early.
   - 🟡 **Neon connections + pgvector indexing** at load (add HNSW/IVFFlat indexes on `knowledge_chunks.embedding`).
   - 🟡 **AI token costs** — need per-tenant budgets/limits so one chatty concierge doesn't burn your margin.

6. **Operations can detect a broken tenant.** Webhook log, selftest cron, and monitoring exist so a silent failure is caught in minutes, not weeks.

**The honest caveat:** code can be *architecturally* 1,000-tenant-ready while you onboard 5. The trap is claiming 1,000-readiness before tenant #1 works end-to-end. Grow 1 → 10 → 100; the Evolution infra is what you scale *ahead* of demand.

```ts
// src/modules/knowledge/service.ts
import { db } from '@/lib/db';
import { knowledgeSources, knowledgeChunks } from '@/lib/db/schema';
import { eq, and, desc, sql } from 'drizzle-orm';
import { embed, embedMany } from 'ai';
import { openai } from '@ai-sdk/openai';
import { extractText, getDocumentProxy } from 'unpdf';

const EMBEDDING_MODEL = openai.embedding('text-embedding-3-small');

function chunkText(text: string, size = 800, overlap = 100): string[] {
  const out: string[] = [];
  for (let i = 0; i < text.length; i += size - overlap) out.push(text.slice(i, i + size));
  return out.filter((c) => c.trim().length > 40);
}

// Jina Reader turns any URL (even JS-rendered sites) into clean markdown.
async function fetchUrlAsText(url: string): Promise<string> {
  const res = await fetch(`https://r.jina.ai/${url}`, { headers: { Accept: 'text/plain' } });
  if (!res.ok) throw new Error('Could not read that URL');
  return res.text();
}

async function parsePdf(buffer: ArrayBuffer): Promise<string> {
  const pdf = await getDocumentProxy(new Uint8Array(buffer));
  const { text } = await extractText(pdf, { mergePages: true });
  return Array.isArray(text) ? text.join('\n') : text;
}

async function embedAndStore(tenantId: string, sourceId: string, rawText: string): Promise<number> {
  const chunks = chunkText(rawText);
  if (!chunks.length) throw new Error('No usable content extracted');
  const { embeddings } = await embedMany({ model: EMBEDDING_MODEL, values: chunks });
  await db!.insert(knowledgeChunks).values(
    chunks.map((content, i) => ({ tenantId, sourceId, content, embedding: embeddings[i] })),
  );
  return chunks.length;
}

async function markFailed(sourceId: string, error: unknown) {
  await db!.update(knowledgeSources)
    .set({ status: 'failed', error: error instanceof Error ? error.message : 'Unknown' })
    .where(eq(knowledgeSources.id, sourceId));
}

export async function ingestUrl(tenantId: string, url: string) {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');
  const [source] = await db.insert(knowledgeSources).values({ tenantId, type: 'url', url, status: 'processing' }).returning();
  try {
    const raw = await fetchUrlAsText(url);
    if (raw.trim().length < 50) throw new Error('Could not extract enough text from that URL');
    const chunks = await embedAndStore(tenantId, source.id, raw);
    await db.update(knowledgeSources).set({ status: 'ready' }).where(eq(knowledgeSources.id, source.id));
    return { sourceId: source.id, chunks };
  } catch (e) {
    await markFailed(source.id, e);
    throw e;
  }
}

export async function ingestPdfBuffer(tenantId: string, filename: string, buffer: ArrayBuffer) {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');
  const [source] = await db.insert(knowledgeSources).values({ tenantId, type: 'pdf', filename, status: 'processing' }).returning();
  try {

    if (raw.trim().length < 50) throw new Error('Could not extract enough text from that PDF');

    await db.update(knowledgeSources).set({ status: 'ready' }).where(eq(knowledgeSources.id, source.id));

    throw e;

/** Re-fetch a URL source whose website has changed. */
export async function reingest(tenantId: string, sourceId: string) {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');
  const [source] = await db.select().from(knowledgeSources)
    .where(and(eq(knowledgeSources.id, sourceId), eq(knowledgeSources.tenantId, tenantId))).limit(1);
  if (!source) throw new Error('SOURCE_NOT_FOUND');
  if (source.type !== 'url' || !source.url) throw new Error('Only website links can be refreshed');

  await db.update(knowledgeSources).set({ status: 'processing', error: null }).where(eq(knowledgeSources.id, sourceId));
  await db.delete(knowledgeChunks).where(eq(knowledgeChunks.sourceId, sourceId));
  try {
    const raw = await fetchUrlAsText(source.url);
    if (raw.trim().length < 50) throw new Error('Could not extract enough text');
    const chunks = await embedAndStore(tenantId, sourceId, raw);
    await db.update(knowledgeSources).set({ status: 'ready' }).where(eq(knowledgeSources.id, sourceId));
    return { chunks };
  } catch (e) {
    await markFailed(sourceId, e);
    throw e;
  }
}

export async function deleteSource(tenantId: string, sourceId: string) {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');
  await db.delete(knowledgeChunks).where(and(eq(knowledgeChunks.sourceId, sourceId), eq(knowledgeChunks.tenantId, tenantId)));
  await db.delete(knowledgeSources).where(and(eq(knowledgeSources.id, sourceId), eq(knowledgeSources.tenantId, tenantId)));
}

export async function listSources(tenantId: string) {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');
  return db
    .select({
      id: knowledgeSources.id,
      type: knowledgeSources.type,
      url: knowledgeSources.url,
      filename: knowledgeSources.filename,
      status: knowledgeSources.status,
      error: knowledgeSources.error,
      createdAt: knowledgeSources.createdAt,
      chunkCount: sql<number>`count(${knowledgeChunks.id})::int`,
    })
    .from(knowledgeSources)
    .leftJoin(knowledgeChunks, eq(knowledgeChunks.sourceId, knowledgeSources.id))
    .where(eq(knowledgeSources.tenantId, tenantId))
    .groupBy(knowledgeSources.id)
    .orderBy(desc(knowledgeSources.createdAt));
}

/** Retrieval used by the concierge + the test endpoint. Tenant-scoped. */
export async function searchKnowledge(tenantId: string, query: string, limit = 5) {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');
  const { embedding } = await embed({ model: EMBEDDING_MODEL, value: query });
  const vec = `[${embedding.join(',')}]`;
  const rows = await db.execute(sql`
    SELECT content, 1 - (embedding <=> ${vec}::vector) AS similarity
    FROM knowledge_chunks
    WHERE tenant_id = ${tenantId}
    ORDER BY embedding <=> ${vec}::vector
    LIMIT ${limit}
  `);
  return rows as unknown as { content: string; similarity: number }[];
}
```

## 1 · The concierge tools (grounded by construction)

Every fact comes from a tool into your own data — the model never answers from memory.

```ts
// src/modules/concierge/tools.ts
import { tool } from 'ai';
import { z } from 'zod';
import { db } from '@/lib/db';
import { menuItems, tenants, guests, rewardsCatalog } from '@/lib/db/schema';
import { eq, and, asc } from 'drizzle-orm';
import { searchKnowledge } from '@/modules/knowledge/service';

/** Tools are built per-request, scoped to this tenant + this guest. */
export function buildConciergeTools(tenantId: string, guestPhone: string) {
  return {
    getMenu: tool({
      description: "Get the restaurant's current menu (categories, dishes, prices). Use when the guest asks about food, dishes, or the menu.",
      parameters: z.object({}),
      execute: async () => {
        if (!db) return { error: 'unavailable' };
        const items = await db.select().from(menuItems)
          .where(and(eq(menuItems.tenantId, tenantId), eq(menuItems.isAvailable, true)))
          .orderBy(asc(menuItems.category), asc(menuItems.sortOrder));
        if (!items.length) return { menu: 'The menu is not available yet.' };
        const grouped: Record<string, string[]> = {};
        for (const it of items) {
          (grouped[it.category] ??= []).push(
            `${it.name} - R${Math.round(it.priceCents / 100)}${it.description ? ` (${it.description})` : ''}`,
          );
        }
        return { menu: grouped };
      },
    }),

    getBusinessInfo: tool({
      description: "Get the restaurant's hours, address, phone, and cuisine. Use for questions about opening times, location, or how to contact them.",
      parameters: z.object({}),
      execute: async () => {
        if (!db) return { error: 'unavailable' };
        const [t] = await db.select().from(tenants).where(eq(tenants.id, tenantId)).limit(1);
        if (!t) return { error: 'not_found' };
        return { name: t.name, cuisine: t.cuisine, address: t.address, phone: t.phone, openingHours: t.openingHours };
      },
    }),

    getSpecials: tool({
      description: "Get today's specials or current promotions. Use when the guest asks about specials, deals, or promotions.",
      parameters: z.object({}),
      execute: async () => {
        if (!db) return { error: 'unavailable' };
        const [t] = await db.select({ cfg: tenants.smartPageConfig }).from(tenants).where(eq(tenants.id, tenantId)).limit(1);
        const specials = (t?.cfg as { todaySpecials?: string } | null)?.todaySpecials;
        return { specials: specials ?? 'No specials are listed right now.' };
      },
    }),

    getLoyaltyBalance: tool({
      description: "Get this guest's loyalty points balance and progress toward their next reward. Use when the guest asks about points, balance, or rewards.",
      parameters: z.object({}),
      execute: async () => {
        if (!db) return { error: 'unavailable' };
        const [guest] = await db.select().from(guests)
          .where(and(eq(guests.tenantId, tenantId), eq(guests.phone, guestPhone))).limit(1);
        if (!guest) return { joined: false, hint: 'This person is not a member yet. Invite them to text JOIN.' };
        const [cheapest] = await db.select().from(rewardsCatalog)
          .where(and(eq(rewardsCatalog.tenantId, tenantId), eq(rewardsCatalog.isActive, true)))
          .orderBy(asc(rewardsCatalog.pointsCost)).limit(1);
        return {
          joined: true,
          name: guest.name,
          points: guest.pointsBalance,
          nextReward: cheapest
            ? { name: cheapest.name, cost: cheapest.pointsCost, pointsNeeded: Math.max(0, cheapest.pointsCost - guest.pointsBalance) }
            : null,
        };
      },
    }),

    searchKnowledge: tool({
      description: "Search the restaurant's own knowledge base (website, menu docs, policies, FAQ). Use for policies, allergens, parking, dress code, story, events, or anything the other tools don't cover.",
      parameters: z.object({ query: z.string().describe('What to search for') }),
      execute: async ({ query }) => {
        const results = await searchKnowledge(tenantId, query, 4);
        if (!results.length) {
          return { found: false, hint: 'Nothing found. Say you are not sure and suggest they call the restaurant. Do not guess.' };
        }
        return { found: true, excerpts: results.map((r) => r.content) };
      },
    }),
  };
}
```

```ts
// src/modules/concierge/service.ts
import { generateText } from 'ai';
import { openai } from '@ai-sdk/openai';
import { db } from '@/lib/db';
import { tenants } from '@/lib/db/schema';
import { eq } from 'drizzle-orm';
import { buildConciergeTools } from './tools';

export async function answerWithConcierge(
  tenantId: string,
  guestPhone: string,
  message: string,
): Promise<string> {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');

  const [tenant] = await db.select().from(tenants).where(eq(tenants.id, tenantId)).limit(1);
  if (!tenant) throw new Error('TENANT_NOT_FOUND');

  const { text } = await generateText({
    model: openai('gpt-4o-mini'),
    // AI SDK v4. On v5 use: stopWhen: stepCountIs(5)
    maxSteps: 5,
    system: buildSystemPrompt(tenant.name, tenant.currencyName ?? 'Points'),
    prompt: message,
    tools: buildConciergeTools(tenantId, guestPhone),
  });

  return text;
}

function buildSystemPrompt(restaurantName: string, currency: string): string {
  return [
    `You are the friendly WhatsApp concierge for ${restaurantName}, a restaurant in South Africa.`,
    `Guests text you questions. You answer by calling your tools to get real information.`,
    ``,
    `GROUNDING RULES (critical):`,
    `- ALWAYS use a tool to get facts (menu, hours, specials, balance, policies). NEVER invent prices, dishes, hours, or policies from memory.`,
```

## 3 · The inbound router (keywords → booking → AI)

```ts
// src/modules/concierge/router.ts
import { handleJoin, handleBalance, handleRedeem, handleStop } from '@/modules/loyalty/service';
import { answerWithConcierge } from '@/modules/concierge/service';
import { sendMessageToGuest } from '@/modules/whatsapp/send';

const BOOKING_HINTS = ['book', 'reserve', 'reservation', 'table for', 'booking'];

export async function routeInboundMessage(tenantId: string, phone: string, rawText: string) {
  const text = rawText.trim();
  const up = text.toUpperCase();

  // 1) Deterministic keywords — business logic stays out of the LLM
  if (up === 'JOIN' || up.startsWith('JOIN ')) return handleJoin(tenantId, phone);
  if (up === 'BALANCE' || up === 'POINTS') return handleBalance(tenantId, phone);
  if (up === 'REDEEM' || up.startsWith('REDEEM')) return handleRedeem(tenantId, phone);
  if (up === 'STOP' || up === 'UNSUBSCRIBE' || up === 'OPT OUT') return handleStop(tenantId, phone);

  // 2) Booking intent → structured prompt (deterministic booking flow is a follow-up)
  if (BOOKING_HINTS.some((k) => up.includes(k))) {
    await sendMessageToGuest(
      tenantId, phone,
      "I'd love to get you booked in! Reply with the date, time, and how many people - e.g. \"Friday 7pm, table for 4\" - and we'll confirm your reservation.",
      { handledBy: 'concierge' },
    );
    return { handled: 'booking_intent' };
  }

  // 3) Everything else → grounded AI concierge
  try {
    const answer = await answerWithConcierge(tenantId, phone, text);
    await sendMessageToGuest(tenantId, phone, answer, { handledBy: 'concierge' });
    return { handled: 'concierge' };
  } catch (e) {
    // Graceful degradation: never leave a guest on read
    console.error('[router] concierge failed, using fallback', e);
    await sendMessageToGuest(
      tenantId, phone,
      'Thanks for your message! Text JOIN to join our rewards, BALANCE to check your points, REDEEM for a reward, or give us a call for anything else.',
      { handledBy: 'fallback' },
    );
    return { handled: 'fallback' };
  }
}
```

```ts
// src/app/api/webhooks/evolution/route.ts
import { NextResponse } from 'next/server';
import { db } from '@/lib/db';
import { tenants, guests, messages } from '@/lib/db/schema';
import { eq, and } from 'drizzle-orm';
import { routeInboundMessage } from '@/modules/concierge/router';

export async function POST(request: Request) {
  try {
    const body = await request.json();

    // Only handle inbound message events
    if (body.event !== 'messages.upsert') return NextResponse.json({ ok: true });

    const instanceName = body.instance?.name ?? body.instance;
    const data = body.data;
    if (!instanceName || !data?.key?.remoteJid) return NextResponse.json({ ok: true });

    // Ignore groups and messages sent by the business itself (loop prevention)
    if (data.key.remoteJid.endsWith('@g.us')) return NextResponse.json({ ok: true });
    if (data.key.fromMe) return NextResponse.json({ ok: true });

    if (!db) return NextResponse.json({ ok: true });

    // Route to the right tenant by Evolution instance
    const [tenant] = await db.select().from(tenants)
      .where(eq(tenants.whatsappInstanceName, instanceName)).limit(1);
    if (!tenant) return NextResponse.json({ ok: true });

    const phone = data.key.remoteJid.split('@')[0];
    const text = extractText(data.message);
    if (!text) return NextResponse.json({ ok: true });

    // Resolve guest (if any) and log the inbound message
    const [guest] = await db.select({ id: guests.id }).from(guests)
      .where(and(eq(guests.tenantId, tenant.id), eq(guests.phone, phone))).limit(1);

    try {
      await db.insert(messages).values({
        tenantId: tenant.id,
        guestId: guest?.id ?? null,
        direction: 'inbound',
        channel: 'whatsapp',
        content: text,
        messageType: 'text',
        status: 'received',
      });
    } catch (e) {
      console.error('[webhook] failed to log inbound', e);
    }

    // Route through keywords → booking → AI concierge
    await routeInboundMessage(tenant.id, phone, text);

    return NextResponse.json({ ok: true });
  } catch (e) {
    console.error('[webhook] evolution error', e);
    // Always 200 so Evolution doesn't retry-storm us
    return NextResponse.json({ ok: true });
  }
}

function extractText(message: any): string | null {
  if (!message) return null;
  if (message.conversation) return message.conversation;
  if (message.extendedTextMessage?.text) return message.extendedTextMessage.text;
  if (message.imageMessage?.caption) return message.imageMessage.caption;
  return null;
}
```

- **No conversation memory yet** — each message is answered standalone. Fine for v1; memory tiers are a later concern.

## 1b · Booking service (AI extract → draft → deterministic create → confirm)

```ts
// src/modules/bookings/service.ts
import { db } from '@/lib/db';
import { bookingDrafts, guests, tenants } from '@/lib/db/schema';
import { eq, and, sql } from 'drizzle-orm';
import { generateObject } from 'ai';
import { openai } from '@ai-sdk/openai';
import { z } from 'zod';
import { sendMessageToGuest } from '@/modules/whatsapp/send';
import { createReservation, checkAvailability } from '@/modules/reservations/service';

const DRAFT_TTL_MINUTES = 30;

/* ── AI extraction: language in, structured fields out ────────────────── */
const extractionSchema = z.object({
  date: z.string().nullable(),            // ISO YYYY-MM-DD
  time: z.string().nullable(),            // HH:MM (24h)
  partySize: z.number().int().min(1).max(30).nullable(),
  occasion: z.string().nullable(),
  specialRequests: z.string().nullable(),
});

export async function extractBookingDetails(text: string) {
  const today = new Date();
  const todayIso = today.toISOString().slice(0, 10);
  const dayName = today.toLocaleDateString('en-ZA', { weekday: 'long' });
  try {
    const { object } = await generateObject({
      model: openai('gpt-4o-mini'),
      schema: extractionSchema,
      prompt: [
        `Today is ${dayName}, ${todayIso}.`,
        `Extract restaurant booking details from the guest's message.`,
        `Resolve relative dates ("today", "tomorrow", "Friday") to ISO YYYY-MM-DD using today's date.`,
        `Return time as 24-hour HH:MM. Return null for any field not mentioned.`,
        ``,
        `Guest message: "${text}"`,
      ].join('\n'),
    });
    return object;
  } catch (e) {
    console.error('[booking] extraction failed', e);
    return { date: null, time: null, partySize: null, occasion: null, specialRequests: null };
  }
}

/* ── Draft helpers ─────────────────────────────────────────────────────── */
async function getActiveDraft(tenantId: string, phone: string) {
  if (!db) return null;
  const [draft] = await db
    .select()
    .from(bookingDrafts)
    .where(and(
      eq(bookingDrafts.tenantId, tenantId),
      eq(bookingDrafts.phone, phone),
      eq(bookingDrafts.status, 'collecting'),
    ))
    .orderBy(sql`${bookingDrafts.updatedAt} desc`)
    .limit(1);
  if (!draft) return null;
  const ageMs = Date.now() - new Date(draft.updatedAt).getTime();
  if (ageMs > DRAFT_TTL_MINUTES * 60 * 1000) {
    await db.update(bookingDrafts).set({ status: 'expired' }).where(eq(bookingDrafts.id, draft.id));
    return null;
  }
  return draft;
}

export async function hasActiveBookingDraft(tenantId: string, phone: string): Promise<boolean> {
  return !!(await getActiveDraft(tenantId, phone));
}

async function findGuest(tenantId: string, phone: string) {
  if (!db) return null;
  const [g] = await db.select().from(guests)
    .where(and(eq(guests.tenantId, tenantId), eq(guests.phone, phone))).limit(1);
  return g ?? null;
}

function missingFields(draft: any): string[] {
  const missing: string[] = [];
  if (!draft.reservationDate) missing.push('the date');
  if (!draft.reservationTime) missing.push('the time');
  if (!draft.partySize) missing.push('how many people');
  return missing;
}

function formatDate(iso: string): string {
  try {
    return new Date(iso + 'T00:00:00').toLocaleDateString('en-ZA', { weekday: 'long', day: 'numeric', month: 'long' });
  } catch { return iso; }
}

/* ── Main entry, called from the router ───────────────────────────────── */
export async function processBookingMessage(tenantId: string, phone: string, text: string) {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');

  const [tenant] = await db.select().from(tenants).where(eq(tenants.id, tenantId)).limit(1);
  const restaurantName = tenant?.name ?? 'our restaurant';

  // 1) AI extracts structured details from this message
  const details = await extractBookingDetails(text);

  // 2) Load or create the draft, then merge non-null fields
  let draft = await getActiveDraft(tenantId, phone);
  const guest = await findGuest(tenantId, phone);

  if (!draft) {
    [draft] = await db.insert(bookingDrafts).values({
      tenantId, phone, guestId: guest?.id ?? null,
      partySize: details.partySize, reservationDate: details.date, reservationTime: details.time,
      occasion: details.occasion, specialRequests: details.specialRequests, status: 'collecting',
    }).returning();
  } else {
    [draft] = await db.update(bookingDrafts).set({
      partySize: details.partySize ?? draft.partySize,
      reservationDate: details.date ?? draft.reservationDate,
      reservationTime: details.time ?? draft.reservationTime,
      occasion: details.occasion ?? draft.occasion,
      specialRequests: details.specialRequests ?? draft.specialRequests,
      updatedAt: new Date(),
    }).where(eq(bookingDrafts.id, draft.id)).returning();
  }

  // 3) Drop past dates so they count as "missing"
  const todayIso = new Date().toISOString().slice(0, 10);
  if (draft.reservationDate && draft.reservationDate < todayIso) {
    [draft] = await db.update(bookingDrafts).set({ reservationDate: null })
      .where(eq(bookingDrafts.id, draft.id)).returning();
  }

  // 4) Complete or ask for what's missing
  const missing = missingFields(draft);
  if (missing.length > 0) {
    const list = missing.map((m) => `• ${m}`).join('\n');
    await sendMessageToGuest(tenantId, phone,
      `I'd love to book you in at ${restaurantName}! I just need:\n${list}\n\nReply like "Friday 7pm for 2". 😊`,
      { guestId: guest?.id ?? null, handledBy: 'concierge' });
    return { status: 'collecting', missing };
  }

  return completeBooking(tenantId, phone, draft, restaurantName);
}

/* ── Create the real reservation + confirm ────────────────────────────── */
async function completeBooking(tenantId: string, phone: string, draft: any, restaurantName: string) {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');
  const guest = await findGuest(tenantId, phone);

  // Best-effort availability pre-check
  try {
    const avail = await checkAvailability(tenantId, draft.reservationDate, draft.reservationTime, draft.partySize);
    if (avail && avail.available === false) {
      const slots = (avail.suggestedSlots ?? []).slice(0, 3).join(', ');
      await sendMessageToGuest(tenantId, phone,
        `Sorry, ${draft.reservationTime} on ${formatDate(draft.reservationDate)} is fully booked.` +
        (slots ? ` We have space at ${slots} instead.` : '') +
        ` Want one of those? Just reply with the time.`,
        { guestId: guest?.id ?? null, handledBy: 'concierge' });
      return { status: 'unavailable' };
    }
  } catch (e) {
    console.warn('[booking] availability check failed, proceeding', e);
  }

  try {
    // Deterministic write via the reservations service (single authority)
    const reservation = await createReservation(tenantId, {
      guestId: guest?.id ?? null,
      reservationDate: draft.reservationDate,
      reservationTime: draft.reservationTime,
      partySize: draft.partySize,
      occasion: draft.occasion ?? undefined,
      specialRequests: draft.specialRequests ?? undefined,
      source: 'whatsapp',
    });

    await db.update(bookingDrafts).set({ status: 'completed' }).where(eq(bookingDrafts.id, draft.id));

    await sendMessageToGuest(tenantId, phone,
      [
        `You're booked in! 🎉`,
        `${restaurantName} — ${formatDate(draft.reservationDate)} at ${draft.reservationTime}, table for ${draft.partySize}.`,
        `Booking ref: ${reservation.bookingRef}`,
        `We'll remind you before your visit. See you soon!`,
      ].join('\n'),
      { guestId: guest?.id ?? null, handledBy: 'concierge' });

    return { status: 'booked', reservation };
  } catch (e) {
    console.error('[booking] create failed', e);
    await sendMessageToGuest(tenantId, phone,
      `Hmm, I couldn't lock in that table just now. Please try again, or give us a call and we'll sort it out right away.`,
      { guestId: guest?.id ?? null, handledBy: 'concierge' });
    return { status: 'failed' };
  }
}
```

```ts
  const text = rawText.trim();
  const up = text.toUpperCase();

  // 1) Deterministic keywords
  if (up === 'JOIN' || up.startsWith('JOIN ')) return handleJoin(tenantId, phone);
  if (up === 'BALANCE' || up === 'POINTS') return handleBalance(tenantId, phone);
  if (up === 'REDEEM' || up.startsWith('REDEEM')) return handleRedeem(tenantId, phone);
  if (up === 'STOP' || up === 'UNSUBSCRIBE' || up === 'OPT OUT') return handleStop(tenantId, phone);

  // 2) Cancel / reschedule (checked before booking intent on purpose)
  if (up === 'CANCEL' || up.startsWith('CANCEL ')) return processCancel(tenantId, phone);
  if (up.includes('RESCHEDULE') || up.includes('MOVE MY BOOKING') || up.includes('CHANGE MY BOOKING')) {

  if (await hasActiveBookingDraft(tenantId, phone)) {
    return processBookingMessage(tenantId, phone, text);
  }

  if (BOOKING_HINTS.some((k) => up.includes(k))) {
```

# Feature 2 · No-show reminder crons (48h / 24h / 6h)

## 2a · The cron endpoint

```ts
// src/app/api/cron/reservation-reminders/route.ts
import { NextResponse } from 'next/server';
import { db } from '@/lib/db';
import { reservations, guests, tenants } from '@/lib/db/schema';
import { and, eq, gte, lte, inArray } from 'drizzle-orm';
import { sendMessageToGuest } from '@/modules/whatsapp/send';
import { getReservationDateTime } from '@/modules/bookings/service';

export const dynamic = 'force-dynamic';

export async function POST(request: Request) {
  const secret = process.env.CRON_SECRET;
  const auth = request.headers.get('authorization') ?? '';
  if (!secret || (auth !== `Bearer ${secret}` && auth !== secret)) {
    return NextResponse.json({ error: { code: 'UNAUTHORIZED' } }, { status: 401 });
  }
  if (!db) return NextResponse.json({ error: { code: 'DATABASE_NOT_CONFIGURED' } }, { status: 503 });

  const now = new Date();

  // Quiet-hours guard: never text before 7am or after 8pm (server time — see notes)
  const hour = now.getHours();
  if (hour < 7 || hour > 20) {
    return NextResponse.json({ ok: true, skipped: 'quiet_hours', sent: 0 });
  }

  const todayIso = toIsoDate(now);
  const plusTwoIso = toIsoDate(new Date(now.getTime() + 2 * 24 * 3600 * 1000));

  const rows = await db.select({
    id: reservations.id,
    tenantId: reservations.tenantId,
    reservationDate: reservations.reservationDate,
    reservationTime: reservations.reservationTime,
    partySize: reservations.partySize,
    bookingRef: reservations.bookingRef,
    r48: reservations.reminder48hSent,
    r24: reservations.reminder24hSent,
    r6: reservations.reminder6hSent,
    guestId: reservations.guestId,
    guestPhone: guests.phone,
    guestName: guests.name,
    restaurantName: tenants.name,
  }).from(reservations)
    .innerJoin(guests, eq(reservations.guestId, guests.id))
    .innerJoin(tenants, eq(reservations.tenantId, tenants.id))
    .where(and(
      inArray(reservations.status, ['pending', 'confirmed']),
      gte(reservations.reservationDate, todayIso),
      lte(reservations.reservationDate, plusTwoIso),
    ));

  let sent = 0;
  for (const r of rows) {
    try {
      const dt = getReservationDateTime(r.reservationDate, r.reservationTime);
      if (!dt) continue;
      const hoursUntil = (dt.getTime() - now.getTime()) / 3600000;
      if (hoursUntil <= 0) continue; // already past

      const name = r.guestName ?? 'there';
      const when = `${formatShortDate(r.reservationDate)} at ${r.reservationTime}`;

      if (hoursUntil <= 48 && hoursUntil > 24 && !r.r48) {
        await sendMessageToGuest(r.tenantId, r.guestPhone,
          `Hi ${name}! Looking forward to seeing you at ${r.restaurantName} ${when}, table for ${r.partySize}. Reply CANCEL if you need to change anything. 😊`,
          { guestId: r.guestId, handledBy: 'automation' });
        await setFlag(r.id, 'reminder48hSent');
        sent++;
      } else if (hoursUntil <= 24 && hoursUntil > 6 && !r.r24) {
        await sendMessageToGuest(r.tenantId, r.guestPhone,
          `See you soon, ${name}! Your table for ${r.partySize} at ${r.restaurantName} is ${when}. Reply CONFIRM to reconfirm, or CANCEL to cancel.`,
          { guestId: r.guestId, handledBy: 'automation' });
        await setFlag(r.id, 'reminder24hSent');
        sent++;
      } else if (hoursUntil <= 6 && !r.r6) {
        await sendMessageToGuest(r.tenantId, r.guestPhone,
          `Hi ${name}, your table for ${r.partySize} at ${r.restaurantName} is today at ${r.reservationTime}. Can we still confirm? Reply CONFIRM to keep it, or CANCEL to release it.`,
          { guestId: r.guestId, handledBy: 'automation' });
        await setFlag(r.id, 'reminder6hSent');
        sent++;
      }
    } catch (e) {
      console.error('[reminders] failed for reservation', r.id, e);
    }
  }

  return NextResponse.json({ ok: true, checked: rows.length, sent });
}

async function setFlag(id: string, field: 'reminder48hSent' | 'reminder24hSent' | 'reminder6hSent') {
  if (!db) return;
  if (field === 'reminder48hSent') await db.update(reservations).set({ reminder48hSent: true }).where(eq(reservations.id, id));
  else if (field === 'reminder24hSent') await db.update(reservations).set({ reminder24hSent: true }).where(eq(reservations.id, id));
  else await db.update(reservations).set({ reminder6hSent: true }).where(eq(reservations.id, id));
}

function toIsoDate(d: Date): string {
  return d.toISOString().slice(0, 10);
}
function formatShortDate(iso: string): string {
  try {
    return new Date(iso + 'T00:00:00').toLocaleDateString('en-ZA', { weekday: 'long', day: 'numeric', month: 'long' });
  } catch { return iso; }
}
```

```ts
/* ── A table freed up → offer it to the best match ──────────────────── */
export async function offerFreedTable(
  tenantId: string, freedDate: string, freedTime: string, freedCapacity: number,
) {
  if (!db) return null;
  const candidates = await db.select().from(waitlist)
    .where(and(eq(waitlist.tenantId, tenantId), eq(waitlist.status, 'waiting')))
    .orderBy(asc(waitlist.createdAt)); // first-come, first-served

  const match = candidates.find((c) => {
    const dateOk = !c.preferredDate || c.preferredDate === freedDate;
    const sizeOk = c.partySize <= freedCapacity;
    return dateOk && sizeOk;
  });
  if (!match) return null;

  const expiresAt = new Date(Date.now() + OFFER_WINDOW_MINUTES * 60 * 1000);
  await db.update(waitlist).set({
    status: 'notified',
    preferredDate: freedDate,          // the slot we're offering
    preferredTime: freedTime,
    notifiedAt: new Date(),
    expiresAt,
    updatedAt: new Date(),
  }).where(eq(waitlist.id, match.id));

  const restaurantName = await getTenantName(tenantId);
  await sendMessageToGuest(tenantId, match.phone,
    `Good news! A table just opened at ${restaurantName} for ${match.partySize} on ${formatDate(freedDate)} at ${freedTime}. Want it? Reply YES in the next ${OFFER_WINDOW_MINUTES} minutes and I'll book it for you. 🎉`,
    { guestId: match.guestId ?? undefined, handledBy: 'automation' });
  return match;
}

/* ── Guest replied YES → book the offered slot ──────────────────────── */
export async function processWaitlistAccept(tenantId: string, phone: string): Promise<boolean> {
  if (!db) return false;
  const now = new Date();

  const [entry] = await db.select().from(waitlist)
    .where(and(
      eq(waitlist.tenantId, tenantId),
      eq(waitlist.phone, phone),
      eq(waitlist.status, 'notified'),
    ))
    .orderBy(asc(waitlist.notifiedAt))
    .limit(1);
  if (!entry) return false;

  // Offer expired
  if (entry.expiresAt && new Date(entry.expiresAt) < now) {
    await db.update(waitlist).set({ status: 'expired', updatedAt: now }).where(eq(waitlist.id, entry.id));
    return false;
  }
  if (!entry.preferredDate || !entry.preferredTime) return false;

  const guest = await findGuestByPhone(tenantId, phone);

  // Best-effort availability (someone may have grabbed it first)
  try {
    const avail = await checkAvailability(tenantId, entry.preferredDate, entry.preferredTime, entry.partySize);
    if (avail && avail.available === false) {
      await db.update(waitlist).set({ status: 'waiting', notifiedAt: null, expiresAt: null, updatedAt: now })
        .where(eq(waitlist.id, entry.id));
      await sendMessageToGuest(tenantId, phone,
        `Ah, sorry — that table just got taken. You're still on the waitlist and I'll text you the next one that opens. 🙏`,
        { guestId: guest?.id ?? undefined, handledBy: 'automation' });
      return true;
    }
  } catch (e) {
    console.warn('[waitlist] availability check failed, proceeding', e);
  }

  try {
    const reservation = await createReservation(tenantId, {
      guestId: guest?.id ?? null,
      reservationDate: entry.preferredDate,
      reservationTime: entry.preferredTime,
      partySize: entry.partySize,
      source: 'waitlist',
    });
    await db.update(waitlist).set({ status: 'booked', updatedAt: now }).where(eq(waitlist.id, entry.id));
    const restaurantName = await getTenantName(tenantId);
    await sendMessageToGuest(tenantId, phone,
      `You're booked in! 🎉 ${restaurantName} — ${formatDate(entry.preferredDate)} at ${entry.preferredTime}, table for ${entry.partySize}. Booking ref: ${reservation.bookingRef}. See you soon!`,
      { guestId: guest?.id ?? undefined, handledBy: 'automation' });
    return true;
  } catch (e) {
    console.error('[waitlist] booking failed', e);
    return false;
  }
}
```

```ts
import { db } from '@/lib/db';
import { reservations, guests, tenants } from '@/lib/db/schema';
import { and, eq, gte, lte, isNull } from 'drizzle-orm';

export const dynamic = 'force-dynamic';

export async function POST(request: Request) {
  const secret = process.env.CRON_SECRET;
  const auth = request.headers.get('authorization') ?? '';
  if (!secret || (auth !== `Bearer ${secret}` && auth !== secret)) {
    return NextResponse.json({ error: { code: 'UNAUTHORIZED' } }, { status: 401 });
  }
  if (!db) return NextResponse.json({ error: { code: 'DATABASE_NOT_CONFIGURED' } }, { status: 503 });

  const now = new Date();
  const twoHoursAgo = new Date(now.getTime() - 2 * 3600 * 1000);
  const oneDayAgo = new Date(now.getTime() - 24 * 3600 * 1000);

  const rows = await db.select({
    id: reservations.id,
    tenantId: reservations.tenantId,
    guestId: reservations.guestId,
    guestPhone: guests.phone,
    guestName: guests.name,
    restaurantName: tenants.name,
  }).from(reservations)
    .innerJoin(guests, eq(reservations.guestId, guests.id))
    .innerJoin(tenants, eq(reservations.tenantId, tenants.id))
    .where(and(
      eq(reservations.status, 'completed'),
      isNull(reservations.reviewRequestedAt),
      lte(reservations.completedAt, twoHoursAgo),
      gte(reservations.completedAt, oneDayAgo), // don't blast old completions
    ));

  let sent = 0;
  for (const r of rows) {
    try {
      await sendMessageToGuest(r.tenantId, r.guestPhone,
        `Thanks for visiting ${r.restaurantName} today, ${r.guestName ?? 'friend'}! 🙏 How was everything? Reply with a number 1-5, or tell us in your own words.`,
        { guestId: r.guestId, handledBy: 'automation' });
      await db.update(reservations).set({ reviewRequestedAt: new Date() }).where(eq(reservations.id, r.id));
      sent++;
    } catch (e) {
      console.error('[review-requests] failed for reservation', r.id, e);
    }
  }
  return NextResponse.json({ ok: true, checked: rows.length, sent });
}
```

```ts
function parseRating(text: string): number | null {
  const m = text.match(/[1-5]/);
  return m ? parseInt(m[0], 10) : null;
}

function analyzeSentiment(text: string): 'positive' | 'negative' | 'neutral' {
  const t = text.toLowerCase();
  const pos = ['great','amazing','love','loved','excellent','delicious','perfect','fantastic','wonderful','good','nice','best'];
  const neg = ['bad','terrible','awful','horrible','slow','cold','rude','disappointing','worst','poor'];
  const posHits = pos.filter((w) => t.includes(w)).length;
  const negHits = neg.filter((w) => t.includes(w)).length;
  if (posHits > negHits) return 'positive';
  if (negHits > posHits) return 'negative';
  return 'neutral';
}

/** Returns true if this message was captured as review feedback. */
export async function processReviewReply(tenantId: string, phone: string, text: string): Promise<boolean> {
  if (!db || !text) return false;
  const guest = await findGuestByPhone(tenantId, phone);
  if (!guest) return false;

  // Latest completed reservation with a review requested in the last 48h
  const [reservation] = await db.select().from(reservations)
    .where(and(
      eq(reservations.tenantId, tenantId),
      eq(reservations.guestId, guest.id),
      eq(reservations.status, 'completed'),
    ))
    .orderBy(desc(reservations.completedAt))
    .limit(1);
  if (!reservation || !reservation.reviewRequestedAt) return false;

  const windowStart = new Date(Date.now() - 48 * 3600 * 1000);
  if (new Date(reservation.reviewRequestedAt) < windowStart) return false;

  // Already reviewed this reservation?
  const [existing] = await db.select({ id: reviews.id }).from(reviews)
    .where(and(eq(reviews.tenantId, tenantId), eq(reviews.reservationId, reservation.id)))
    .limit(1);
  if (existing) return false;

  const [tenant] = await db.select().from(tenants).where(eq(tenants.id, tenantId)).limit(1);

  const rating = parseRating(text);
  const sentiment = rating
    ? (rating >= 4 ? 'positive' : rating <= 2 ? 'negative' : 'neutral')
    : analyzeSentiment(text);
  const routedTo = sentiment === 'positive' ? 'google_review' : 'private_feedback';

  await db.insert(reviews).values({
    tenantId,
    guestId: guest.id,
    reservationId: reservation.id,
    rating,
    sentiment,
    feedbackText: text,
    routedTo,
    googleReviewLinkSent: sentiment === 'positive',
    managerAlerted: sentiment === 'negative',
  });

  if (sentiment === 'positive') {
    const link = tenant?.googleReviewUrl;
    await sendMessageToGuest(tenantId, phone,
      `That's wonderful to hear, thank you! 🙏 If you have a moment, a quick Google review helps more than you know: ${link ?? 'search us on Google'}. See you again soon!`,
      { guestId: guest.id, handledBy: 'automation' });
  } else if (sentiment === 'negative') {
    await sendMessageToGuest(tenantId, phone,
      `Thank you for the honest feedback — I'm really sorry we didn't hit the mark. The manager has been notified and will reach out personally to make it right.`,
      { guestId: guest.id, handledBy: 'automation' });
    try {
      await sendMessageToOwner(tenantId,
        `⚠️ Negative feedback from ${guest.name ?? phone} (reservation ${reservation.bookingRef}): "${text}"`,
        { handledBy: 'automation' });
    } catch (e) {
      console.warn('[reviews] manager alert failed', e);
    }
  } else {
    await sendMessageToGuest(tenantId, phone,
      `Thanks for the feedback! We're always working to make it even better. Hope to see you again soon. 😊`,
      { guestId: guest.id, handledBy: 'automation' });
  }
  return true;
}
```

```ts
  if (up === 'CANCEL' || up.startsWith('CANCEL ')) return processCancel(tenantId, phone);

  if (await hasActiveBookingDraft(tenantId, phone)) {
    return processBookingMessage(tenantId, phone, text);
  }

  // 5) New booking intent
  if (BOOKING_HINTS.some((k) => up.includes(k))) {
```

## Wiring & verify

1. `drizzle-kit push` (adds `waitlist`, `reviews`, and `reservations.review_requested_at`).
2. **Waitlist:** text `WAITLIST` → you're added. Cancel an existing booking (text `CANCEL`) → the waitlisted number gets the "a table just opened" offer. Reply `YES` → it books and you get a ref. Reply after 30 min → it's expired.
3. **Review request:** mark a reservation `completed` with `completed_at` ~2h ago, run the review-requests cron → guest gets "How was everything?". Reply `5` → positive path sends the Google link. Reply `1` or `"the food was cold"` → private apology + manager alert. Check the `reviews` row.
4. **Routing priority:** confirm `BALANCE`/`BOOK` still work even when a review request is pending (keywords/booking are checked before review capture).

## Honest notes & follow-ups

- **Waitlist matching is simple** — date match (or flexible) + party fits + FIFO. Time-proximity matching and real table/capacity shapes are a follow-up.
- **Freed capacity** uses the cancelled reservation's `partySize` as a proxy until you have a real tables model.
- **Sentiment is keyword-based** when there's no 1–5 rating. Upgrade to AI sentiment if you want more nuance.
- **Stale offers:** if a guest never replies to an offer, the entry sits in `notified`. A small cleanup job to expire + re-offer is a follow-up.
- **Timezone:** the 2-hour window uses server time — pin `Africa/Johannesburg` for production.

```ts
import { db } from '@/lib/db';
import { tenants, guests, reservations } from '@/lib/db/schema';

const LARGE_GROUP_THRESHOLD = 6;

export interface DailyBrief {
  tenantId: string;
  restaurantName: string;
  date: string;
  bookingsCount: number;
  bookedCovers: number;
  capacity: number | null;
  availableCovers: number | null;
  expectedRevenueCents: number;
  bookings: { time: string; partySize: number; name: string | null; occasion: string | null; isVip: boolean }[];
  vips: { name: string | null; time: string; partySize: number }[];
  birthdays: { name: string | null }[];
  allergies: { name: string | null; note: string }[];
  largeGroups: { time: string; partySize: number; name: string | null }[];
}

export async function buildDailyBrief(tenantId: string): Promise<DailyBrief | null> {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');
  const now = new Date();
  const todayIso = now.toISOString().slice(0, 10);

  const [tenant] = await db.select().from(tenants).where(eq(tenants.id, tenantId)).limit(1);
  if (!tenant) return null;

  // Today's bookings with guest details
  const rows = await db.select({
    reservationTime: reservations.reservationTime,
    partySize: reservations.partySize,
    occasion: reservations.occasion,
    resAllergies: reservations.allergies,
    guestName: guests.name,
    guestStatus: guests.status,
    guestAllergies: guests.allergies,
  }).from(reservations)
    .leftJoin(guests, eq(reservations.guestId, guests.id))
    .where(and(
      eq(reservations.tenantId, tenantId),
      eq(reservations.reservationDate, todayIso),
      inArray(reservations.status, ['pending', 'confirmed', 'seated']),
    ))
    .orderBy(asc(reservations.reservationTime));

  // Birthdays today
  const monthNum = now.getMonth() + 1;
  const dayNum = now.getDate();
  const birthdays = await db.select({ name: guests.name }).from(guests)
    .where(and(
      eq(guests.tenantId, tenantId),
      sql`EXTRACT(MONTH FROM ${guests.birthday}) = ${monthNum}`,
      sql`EXTRACT(DAY FROM ${guests.birthday}) = ${dayNum}`,
    ));

  const bookings = rows.map((r) => ({
    time: r.reservationTime,
    partySize: r.partySize,
    name: r.guestName,
    occasion: r.occasion,
    isVip: r.guestStatus === 'vip',
  }));

  const bookedCovers = rows.reduce((s, r) => s + (r.partySize ?? 0), 0);
  const avgSpend = tenant.avgSpend ?? 0;
  const capacity = tenant.capacity ?? null;

  const allergies: DailyBrief['allergies'] = [];
  for (const r of rows) {
    const note = r.guestAllergies || r.resAllergies;
    if (note) allergies.push({ name: r.guestName, note });
  }

  return {
    tenantId,
    restaurantName: tenant.name,
    date: todayIso,
    bookingsCount: rows.length,
    bookedCovers,
    capacity,
    availableCovers: capacity != null ? Math.max(0, capacity - bookedCovers) : null,
    expectedRevenueCents: bookedCovers * avgSpend,
    bookings,
    vips: rows.filter((r) => r.guestStatus === 'vip').map((r) => ({ name: r.guestName, time: r.reservationTime, partySize: r.partySize })),
    birthdays: birthdays.map((b) => ({ name: b.name })),
    allergies,
    largeGroups: rows.filter((r) => r.partySize >= LARGE_GROUP_THRESHOLD).map((r) => ({ time: r.reservationTime, partySize: r.partySize, name: r.guestName })),
  };
}

export function formatDailyBriefForWhatsApp(b: DailyBrief): string {
  const lines: string[] = [];
  lines.push(`☀️ Good morning! Here's today at ${b.restaurantName}.`);
  lines.push('');
  lines.push(`📋 *Bookings:* ${b.bookingsCount} (${b.bookedCovers} covers)`);
  for (const bk of b.bookings.slice(0, 10)) {
    let s = `  ${bk.time} — table for ${bk.partySize}`;
    if (bk.name) s += ` · ${bk.name}`;
    if (bk.isVip) s += ' ⭐';
    if (bk.occasion) s += ` (${bk.occasion})`;
    lines.push(s);
  }
  if (b.bookingsCount > 10) lines.push(`  …and ${b.bookingsCount - 10} more`);
  lines.push('');
  if (b.vips.length) lines.push(`⭐ *VIPs today:* ${b.vips.map((v) => v.name ?? 'Guest').join(', ')}`);
  if (b.birthdays.length) lines.push(`🎂 *Birthdays today:* ${b.birthdays.map((x) => x.name ?? 'Guest').join(', ')}`);
  if (b.allergies.length) lines.push(`⚠️ *Allergies:* ${b.allergies.map((a) => `${a.name ?? 'Guest'} — ${a.note}`).join('; ')}`);
  if (b.largeGroups.length) lines.push(`👥 *Large groups:* ${b.largeGroups.map((g) => `${g.time} (${g.partySize})`).join(', ')}`);
  if (b.expectedRevenueCents > 0) lines.push(`💰 *Expected revenue:* ~R${Math.round(b.expectedRevenueCents / 100).toLocaleString()}`);
  if (b.availableCovers != null) lines.push(`🪑 *Seats still available:* ${b.availableCovers} of ${b.capacity}`);
  lines.push('');
  lines.push('Have a great service! 🔥');
  return lines.join('\n');
}
```

```ts
// src/app/api/cron/daily-brief/route.ts

import { db } from '@/lib/db';

  const auth = request.headers.get('authorization') ?? '';
  if (!secret || (auth !== `Bearer ${secret}` && auth !== secret)) {
    return NextResponse.json({ error: { code: 'UNAUTHORIZED' } }, { status: 401 });

  if (!db) return NextResponse.json({ error: { code: 'DATABASE_NOT_CONFIGURED' } }, { status: 503 });

  for (const t of activeTenants) {

      const brief = await buildDailyBrief(t.id);
      if (!brief) continue;

      if (res.success) sent++;
    } catch (e) {
      console.error('[daily-brief] failed for tenant', t.id, e);
    }
  }
  return NextResponse.json({ ok: true, tenants: activeTenants.length, sent });
}
```

```ts
// src/modules/rewards/service.ts
import { db } from '@/lib/db';
import { rewardEvents, rewardsCatalog, loyaltyTransactions, guests, tenants } from '@/lib/db/schema';
import { eq, and, desc } from 'drizzle-orm';
import crypto from 'crypto';
import { sendMessageToGuest } from '@/modules/whatsapp/send';

const CLAIM_WINDOW_MINUTES = 15;
export const CLAIM_RADIUS_METERS = 500;

function haversineMeters(lat1: number, lng1: number, lat2: number, lng2: number): number {
  const R = 6371000;
  const toRad = (d: number) => (d * Math.PI) / 180;
  const dLat = toRad(lat2 - lat1);
  const dLng = toRad(lng2 - lng1);
  const a = Math.sin(dLat / 2) ** 2 + Math.cos(toRad(lat1)) * Math.cos(toRad(lat2)) * Math.sin(dLng / 2) ** 2;
  return 2 * R * Math.asin(Math.sqrt(a));
}

function makeCashierCode(claimToken: string): string {
  return claimToken.replace(/-/g, '').slice(0, 6).toUpperCase();
}

async function findGuestByPhone(tenantId: string, phone: string) {
  if (!db) return null;
  const [g] = await db.select().from(guests)
    .where(and(eq(guests.tenantId, tenantId), eq(guests.phone, phone))).limit(1);
  return g ?? null;
}

/* ── REDEEM keyword → create pending claim + send geo link ─────────── */
export async function processRedeem(tenantId: string, phone: string) {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');
  const guest = await findGuestByPhone(tenantId, phone);
  if (!guest) {
    await sendMessageToGuest(tenantId, phone, `Text JOIN first and start earning rewards. 😊`, { handledBy: 'keyword' });
    return { status: 'no_guest' };
  }

  const [tenant] = await db.select().from(tenants).where(eq(tenants.id, tenantId)).limit(1);
  const currency = tenant?.currencyName ?? 'Points';

  const rewards = await db.select().from(rewardsCatalog)
    .where(and(eq(rewardsCatalog.tenantId, tenantId), eq(rewardsCatalog.isActive, true)))
    .orderBy(desc(rewardsCatalog.pointsCost));

  const affordable = rewards.filter((r) => r.pointsCost <= guest.pointsBalance);
  if (!affordable.length) {
    const cheapest = rewards[rewards.length - 1] ?? null;
    const needed = cheapest ? cheapest.pointsCost - guest.pointsBalance : null;
    await sendMessageToGuest(tenantId, phone,
      needed != null
        ? `You're ${needed} ${currency} away from "${cheapest.name}". Keep visiting and you'll get there! 💪`
        : `No rewards are set up yet — check back soon.`,
      { guestId: guest.id, handledBy: 'keyword' });
    return { status: 'insufficient_points' };
  }

  const reward = affordable[0]; // best reward they can afford
  const claimToken = crypto.randomUUID();
  const expiresAt = new Date(Date.now() + CLAIM_WINDOW_MINUTES * 60 * 1000);

  await db.insert(rewardEvents).values({
    tenantId, guestId: guest.id, rewardId: reward.id,
    status: 'pending', claimToken, expiresAt,
  });

  const appUrl = process.env.NEXT_PUBLIC_APP_URL || '';
  await sendMessageToGuest(tenantId, phone,
    `🎁 You're redeeming "${reward.name}"!\n\nTap to claim: ${appUrl}/geo-claim/${claimToken}\n\nYou need to be at the restaurant to unlock it. Link expires in ${CLAIM_WINDOW_MINUTES} minutes.`,
    { guestId: guest.id, handledBy: 'keyword' });
  return { status: 'pending', claimToken };
}

/* ── GPS check + claim (server-side, never trusts the client) ──────── */
export async function validateAndClaimReward(claimToken: string, lat: number, lng: number) {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');

  const [event] = await db.select().from(rewardEvents).where(eq(rewardEvents.claimToken, claimToken)).limit(1);
  if (!event) return { ok: false as const, code: 'NOT_FOUND' };
  if (event.status === 'claimed') return { ok: false as const, code: 'ALREADY_CLAIMED' };
  if (event.status !== 'pending') return { ok: false as const, code: 'INVALID' };
  if (event.expiresAt && new Date(event.expiresAt) < new Date()) {
    await db.update(rewardEvents).set({ status: 'expired' }).where(eq(rewardEvents.id, event.id));
    return { ok: false as const, code: 'EXPIRED' };
  }

  const [tenant] = await db.select().from(tenants).where(eq(tenants.id, event.tenantId)).limit(1);
  const [reward] = await db.select().from(rewardsCatalog).where(eq(rewardsCatalog.id, event.rewardId)).limit(1);
  const [guest] = await db.select().from(guests).where(eq(guests.id, event.guestId)).limit(1);
  if (!tenant || !reward || !guest) return { ok: false as const, code: 'INVALID' };

  // GPS gate
  if (tenant.gpsLat != null && tenant.gpsLng != null) {
    const distance = haversineMeters(lat, lng, Number(tenant.gpsLat), Number(tenant.gpsLng));
    if (distance > CLAIM_RADIUS_METERS) {
      return { ok: false as const, code: 'TOO_FAR', distanceMeters: Math.round(distance) };
    }
  }
  // If the restaurant hasn't set its location, we allow the claim (see notes).

  if (guest.pointsBalance < reward.pointsCost) {
    return { ok: false as const, code: 'INSUFFICIENT_POINTS' };
  }

  // Optimistic double-claim guard: only claim if still pending
  const [claimed] = await db.update(rewardEvents)
    .set({ status: 'claimed', claimedAt: new Date(), gpsLat: String(lat), gpsLng: String(lng) })
    .where(and(eq(rewardEvents.id, event.id), eq(rewardEvents.status, 'pending')))
    .returning();
  if (!claimed) return { ok: false as const, code: 'ALREADY_CLAIMED' };

  await db.insert(loyaltyTransactions).values({
    tenantId: event.tenantId, guestId: guest.id,
    type: 'redeem', points: -reward.pointsCost,
    description: `Redeemed: ${reward.name}`,
  });
  await db.update(guests)
    .set({ pointsBalance: guest.pointsBalance - reward.pointsCost })
    .where(eq(guests.id, guest.id));

  return {
    ok: true as const,
    rewardName: reward.name,
    restaurantName: tenant.name,
    cashierCode: makeCashierCode(claimToken),
    claimToken,
  };
}

/* ── Staff verification (by token from the QR) ─────────────────────── */
export async function verifyClaim(claimToken: string) {
  if (!db) throw new Error('DATABASE_NOT_CONFIGURED');
  const [event] = await db.select().from(rewardEvents).where(eq(rewardEvents.claimToken, claimToken)).limit(1);
  if (!event) return { valid: false, code: 'NOT_FOUND' };
  const [reward] = await db.select().from(rewardsCatalog).where(eq(rewardsCatalog.id, event.rewardId)).limit(1);
  const [guest] = await db.select().from(guests).where(eq(guests.id, event.guestId)).limit(1);
  return {
    valid: event.status === 'claimed',
    status: event.status,
    rewardName: reward?.name ?? null,
    guestName: guest?.name ?? null,
    claimedAt: event.claimedAt,
  };
}
```

```ts
import { z } from 'zod';

export async function POST(request: Request, { params }: { params: Promise<{ token: string }> }) {
  const { token } = await params;
  const parsed = z.object({ lat: z.number(), lng: z.number() }).safeParse(await request.json().catch(() => null));
  if (!parsed.success) return NextResponse.json({ error: { code: 'VALIDATION' } }, { status: 400 });

  if (!result.ok) {
    const status = result.code === 'NOT_FOUND' || result.code === 'INVALID' ? 404 : 400;
    return NextResponse.json(result, { status });
  }
  return NextResponse.json(result);
}
```

```tsx
import { useState } from 'react';

import { MapPin, Loader2, CheckCircle2, XCircle, Gift, Clock } from 'lucide-react';

export function GeoClaimClient({ token, initial }: { token: string; initial: any }) {
  const [phase, setPhase] = useState<'idle' | 'locating' | 'claiming' | 'success' | 'too_far' | 'error'>('idle');
  const [distance, setDistance] = useState<number | null>(null);
  const [result, setResult] = useState<{ cashierCode: string; claimToken: string } | null>(null);
  const [errorMsg, setErrorMsg] = useState('');
  const brand = initial.brandColour ?? '#e8722a';

  if (initial.status === 'invalid') return <StateCard icon={<XCircle />} title="Link not valid" body="This reward link isn't recognised. Text REDEEM again to get a fresh one." />;
  if (initial.status === 'expired') return <StateCard icon={<Clock />} title="Link expired" body="Reward links last 15 minutes. Text REDEEM again when you're here." />;
  if (initial.status === 'claimed') return <StateCard icon={<CheckCircle2 />} title="Already claimed" body="This reward has already been redeemed." />;

  async function claim() {
    setPhase('locating');
    if (!navigator.geolocation) { setPhase('error'); setErrorMsg('Location is not supported on this device.'); return; }
    navigator.geolocation.getCurrentPosition(async (pos) => {
      setPhase('claiming');
      try {
        const res = await fetch(`/api/v1/geo-claim/${token}/claim`, {
          method: 'POST', headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ lat: pos.coords.latitude, lng: pos.coords.longitude }),
        });
        const data = await res.json();
        if (data.ok) { setResult(data); setPhase('success'); }
        else if (data.code === 'TOO_FAR') { setDistance(data.distanceMeters); setPhase('too_far'); }
        else { setPhase('error'); setErrorMsg(data.code === 'EXPIRED' ? 'This link expired.' : 'Something went wrong. Please try again.'); }
      } catch { setPhase('error'); setErrorMsg('Something went wrong. Please try again.'); }
    }, () => { setPhase('error'); setErrorMsg('We could not get your location. Please allow location access and try again.'); });
  }

  return (
    <div className="min-h-screen bg-[#faf6f0] text-[#241c14] flex items-center justify-center p-5">
      <div className="w-full max-w-sm rounded-3xl border border-[#eadfd2] bg-white p-7 text-center shadow-sm">
        <div className="mx-auto flex h-14 w-14 items-center justify-center rounded-full" style={{ background: `${brand}1a` }}>
          <Gift className="h-7 w-7" style={{ color: brand }} />
        </div>
        <h1 className="mt-4 text-2xl font-semibold [font-family:var(--font-display)]">{initial.rewardName}</h1>
        <p className="mt-1 text-sm text-[#7c6f5f]">at {initial.restaurantName}</p>

        {phase === 'idle' && (
          <button onClick={claim} className="mt-6 flex w-full items-center justify-center gap-2 rounded-full py-3 text-sm font-semibold text-white transition" style={{ background: brand }}>
            <MapPin className="h-4 w-4" /> I&apos;m here — claim it
          </button>
        )}
        {(phase === 'locating' || phase === 'claiming') && (
          <div className="mt-6 flex items-center justify-center gap-2 text-sm text-[#7c6f5f]">
            <Loader2 className="h-4 w-4 animate-spin" style={{ color: brand }} />
            {phase === 'locating' ? 'Finding your location…' : 'Confirming your reward…'}
          </div>
        )}
        {phase === 'too_far' && (
          <div className="mt-6 rounded-2xl bg-[#faf3ea] p-4 text-sm">
            <p className="font-medium">You&apos;re a bit too far away.</p>
            {distance != null && <p className="mt-1 text-[#7c6f5f]">You&apos;re about {distance}m away. You need to be within 500m of the restaurant.</p>}
```

## Wiring & verify

1. `drizzle-kit push` (adds `reward_events`).
2. **Daily brief:** set a few bookings for today (one VIP, one party of 8, one with allergies), run `curl -X POST .../api/cron/daily-brief -H "Authorization: Bearer <CRON_SECRET>"` → the owner's WhatsApp gets the brief. Check `GET /api/v1/brief/today` returns the same data.
3. **Redeem:** make sure the guest has points and there's an active reward. Text `REDEEM` → they get the geo-claim link.
4. **GPS gate:** open the link far from the restaurant → "too far" with distance. At the restaurant (or with tenant GPS unset) → claim succeeds, points deducted, `reward_events` = `claimed`, a `redeem` transaction logged.
5. **Cashier QR:** after success, the QR + 6-char code shows. Hit `GET /api/v1/rewards/verify/<token>` → `{ valid: true, ... }`.
6. **Expiry/double-claim:** reuse a claimed token → "already claimed." Wait 15 min → "expired."

## Honest notes & follow-ups

- **Timezone:** the brief's "today" and the cron schedule use server time — pin `Africa/Johannesburg` for production and tune the cron to real opening time.
- **Brief dedupe:** if the cron fires twice, the brief sends twice. Add a `last_brief_sent` guard if that's a risk.
- **GPS fail-open:** if the restaurant hasn't set its location, claims are allowed. Prompt owners to set their GPS in Settings; consider a hard block once location is mandatory.
- **Point deduction isn't in a DB transaction** (Neon serverless). The optimistic `status='pending'` guard prevents double-claims; wrap in a real transaction if you move to a pooled client.
- **Reward choice:** REDEEM auto-picks the best affordable reward. Letting guests choose among several is a nice follow-up.
- **Cashier manual-entry lookup:** verification currently works via the QR token; entering the 6-char code by hand needs a code-indexed lookup (follow-up).
